# SOLmate Mobile App

React Native app for Solana Seeker phone.

## Setup

```bash
npm install
```

## Run

```bash
# Start Expo development server
npx expo start

# Run on Android (Solana Seeker)
npx expo start --android

# Run on iOS
npx expo start --ios

# Run on web (for testing)
npx expo start --web
```

## For Solana Seeker

The app is optimized for Solana Seeker phone:
- Portrait orientation only
- Dark mode UI
- Solana Mobile Stack integration (coming next)
- Required permissions: Location, Camera, Bluetooth
